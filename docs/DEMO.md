# Demo script

1. Sign in with Privy and show the embedded wallet address and live Arc balance.
2. Transfer USDC to the Circle Developer-Controlled Wallet and wait for the confirmed Arc transaction.
3. Enter an objective and a hard maximum price on `/agent`.
4. Show live Marketplace discovery, endpoint inspection, Arc-compatible payment filtering, Graph freshness, and the deterministic risk table.
5. Run the selected service through the Witness. Show payment confirmation, real HTTP status and latency, evidence CID, receipt digest, and Arc transaction.
6. Query the receipt from the live Graph and run the same objective again so the new receipt is part of the evidence set.
7. Show a real ERC-8183 Protected Job lifecycle only when a participating provider, funded escrow, deliverable, and evaluator transaction are available.

Use the phrase `XYX Observed Evidence` in the demo. It describes the limited history observed by this deployment and does not claim universal provider reputation or complete Sybil resistance.
